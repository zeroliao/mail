# MailOps 文档索引

本目录只保留可持续维护的项目文档。新会话先阅读根目录 `AGENTS.md`，再阅读 `current-state.md`，即可获得开发所需的边界和当前上下文。

| 文档                                   | 权威范围                                       | 何时更新                           |
| -------------------------------------- | ---------------------------------------------- | ---------------------------------- |
| `../README.md`                         | 项目入口、快速启动、功能概览                   | 启动方式、活动模块或核心功能变化时 |
| `../AGENTS.md`                         | Agent 规则、命令、代码边界、验证要求           | 长期工程约束变化时                 |
| `current-state.md`                     | 当前实现、近期改动、已知风险、下一会话检查清单 | 每次较大功能或交接前               |
| `usage-guide.md`                       | 用户流程、账号状态、主要 API                   | 页面流程或 API 行为变化时          |
| `testing.md`                           | 自动化覆盖、人工验收、发布前检查               | 测试覆盖或关键流程变化时           |
| `../mail-backend/docs/architecture.md` | 后端分层、认证、数据和 provider 边界           | 后端架构或数据契约变化时           |
| `../DEPLOYMENT.md`                     | 环境、启动、Docker、生产约束                   | 配置或部署方式变化时               |
| `../CONTRIBUTING.md`                   | 分支、提交和交付约定                           | 团队协作方式变化时                 |

维护原则：同一事实只保留一个权威来源，其他文档使用链接引用；不记录 secrets、邮箱凭据、实际账号清单、临时端口冲突或一次性测试日志。
