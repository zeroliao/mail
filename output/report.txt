== 交付内容（已改代码）==
1) microsoft-mail.provider.ts：requestToken 拆分为两条路径——confidential（env 应用，带 client_secret）与 public client（per-account clientId，body 不带 client_secret）；refreshAccessToken(refreshToken, options?) 支持传入 clientId 走 public 刷新；新增 exchangeRefreshTokenForPublicClient（换 token + 拉 Graph /me 连通性校验，tenant 默认 consumers，scope 默认 Graph：Mail.ReadWrite/Mail.Send/offline_access）。
2) 新接口：POST /api/v1/accounts/bind-oauth（单个）、POST /api/v1/accounts/bind-oauth/batch（批量 ≤100）。入参 email、refreshToken、clientId（可选 displayName、password、tenant、scope）。
3) 落库：accessToken=换到的 access_token（加密）、refreshToken=刷新令牌（加密，优先用微软轮换后新值）、metadata.authMethod='oauth-refresh'、metadata.clientId（加密）、tenant、provider=MICROSOFT；连通性校验成功才落 ACTIVE，失败返回携带微软原始错误体的 502。
4) 收发统一走现有 Graph provider；getAuthorizedAccount 检测 oauth-refresh 账号时用 per-account clientId 自动刷新（buildRefreshOptions）。
5) detectProvider/registry 无需改动——bind-oauth 直接固定 MICROSOFT 入池，路由现成。

== curl 调用示例 ==
TOKEN=$(curl -s -X POST http://localhost:3002/api/v1/auth/login -H 'Content-Type: application/json' -d '{"username":"admin","password":"<API_ADMIN_PASSWORD>"}' | jq -r .token)

# 单个
curl -X POST http://localhost:3002/api/v1/accounts/bind-oauth -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' -d '{"email":"owner@hotmail.com","clientId":"<CLIENT_ID>","refreshToken":"<REFRESH_TOKEN>"}'

# 批量
curl -X POST http://localhost:3002/api/v1/accounts/bind-oauth/batch -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' -d '[{"email":"a@hotmail.com","clientId":"<C1>","refreshToken":"<R1>"}]'
